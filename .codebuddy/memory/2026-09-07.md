# 2026-09-07

## 修复：package.json 远程 schema 加载告警
- 现象：IDE 报 `Problems loading reference 'https://www.schemastore.org/package'`（getaddrinfo ENOTFOUND），定位在 package.json 第 1 行。
- 根因：`package.json` 内并无 `$schema` 字段；告警来自 IDE 对文件名 package.json 的自动 schema 关联并尝试联网下载，机器无法解析 schemastore.org 域名（离线/内网）。
- 修复：在 `.vscode/settings.json` 追加 `"json.schemaDownload.enable": false`，禁止远程 JSON Schema 下载。
- 备注：本项目离线环境下 tsconfig.json 等也可能触发同类远程 schema 警告，该配置可一并覆盖。
